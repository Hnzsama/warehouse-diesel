## Primary Objective

Membangun website Sistem Informasi Manajemen Stok Barang berbasis Modern Monolith (Laravel 13 + React 19 + Inertia v3) yang memperlihatkan alur:

```
Admin Gudang / Pemilik
➔ Login / Auth
➔ Dashboard Monitoring (Real-time Stock & Safety Stock Alert)
➔ Master Data (Sparepart, Kategori, Satuan, Supplier)
➔ Input Barang Masuk (Auto-increment Stok)
➔ Input Barang Keluar (Auto-decrement Stok & Proteksi Stok Minus)
➔ Stock Opname (Penyesuaian Stok Rusak/Hilang)
➔ Laporan Persediaan (Cetak, PDF, Excel)
```
