Panduan Operasional — Admin Gudang

Sistem Informasi Manajemen Stok Barang Gudang Diesel Truk Medan

Kembali ke Docs

1. Pengelolaan Master Data Sparepart

Admin memiliki akses penuh untuk menambah, mengedit, dan menghapus master data suku cadang (kode barang, nama barang, lokasi rak, stok awal, dan stok minimum).

2. Input Transaksi Barang Masuk

Pilih supplier dan item barang yang diterima. Setelah disimpan, jumlah stok item pada sistem akan **bertambah secara otomatis (Auto-increment)**.

3. Input Transaksi Barang Keluar

Pilih barang dan masukkan penerima (mekanik/no. truk). Sistem akan **mengurangi stok secara otomatis (Auto-decrement)**. Apabila jumlah pengeluaran melebihi sisa stok, transaksi akan ditolak (**Proteksi Stok Minus**).

4. Stock Opname (Penyesuaian Stok)

Lakukan penyesuaian jumlah persediaan apabila terdapat selisih fisik vs sistem akibat barang rusak atau hilang. Sistem akan mencatat riwayat penyesuaian pada audit log.
