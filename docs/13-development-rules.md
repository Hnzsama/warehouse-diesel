# 13. Development Rules & Standards

1. **Strict Scope Control:** Setiap fitur wajib mengacu pada scope skripsi Gudang Diesel Truk Medan.
2. **Test Driven Verification:** Seluruh perubahan fitur mutasi stok wajib dilengkapi unit/feature test Pest.
3. **Pint Formatting:** Seluruh berkas PHP wajib diformat menggunakan `vendor/bin/pint --dirty --format agent`.
